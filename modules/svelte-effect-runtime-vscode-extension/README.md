# Svelte Effect Runtime (VS Code)

VS Code / Cursor extension that wires the `svelte-effect-runtime` language server into your editor. Provides TypeScript diagnostics, hover types, and go-to-definition for `<script effect>` blocks and `yield*` expressions inside Svelte components.

- Activates on startup and configures the Svelte extension automatically
- Bundles a compatible language server — no separate install needed
- Adds `svelte-effect-runtime.enableLanguageServer` / `disableLanguageServer` commands for manual control
- Works alongside the stock [Svelte for VS Code](https://marketplace.visualstudio.com/items?itemName=svelte.svelte-vscode) extension

Visit the [docs](https://ser.barekey.dev) for more information.
