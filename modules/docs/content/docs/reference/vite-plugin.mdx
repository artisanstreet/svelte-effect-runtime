---
title: Vite Plugin
description: Reference for the effect Vite plugin.
---

The `effect()` Vite plugin handles runtime integration around SvelteKit: component syntax lowering, server-side import rewrites, and generated remote-client wrappers.

## Example

```ts
import { sveltekit } from "@sveltejs/kit/vite";
import { defineConfig } from "vite";
import { effect } from "svelte-effect-runtime";

export default defineConfig({
	plugins: [effect(), sveltekit()],
});
```

## Notes

- The plugin is required for `<script effect>`, markup `yield*`, remote client wrappers, and server runtime import rewrites in configured Svelte component modules.
- Remote functions also require SvelteKit's `kit.experimental.remoteFunctions` flag.
- Keep plugin configuration close to the default unless you are debugging transform behavior.
- Parser-style Vite plugins that run their Svelte component transform with
  `transform.order = "pre"` can be incompatible because they may parse SER
  syntax before normal source transforms run.
