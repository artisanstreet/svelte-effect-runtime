---

Client APIs configure how component effects run in the browser.

## ClientRuntime.make

```ts
import { ClientRuntime } from "svelte-effect-runtime";

ClientRuntime.make(layer);
```

Registers the layer used by browser-side Effect programs. Call it once from `src/hooks.client.ts`.

## Live.status

```ts
import { Live } from "svelte-effect-runtime";

const status = clock.pipe(Live.status);
```

Returns a Stream of transport status snapshots for a `RemoteLiveStream`. The helper can also be called directly as `Live.status(clock)`.

## Live.reconnect

```ts
import { Live } from "svelte-effect-runtime";

const reconnect = clock.pipe(Live.reconnect);
```

Returns an Effect that asks the live query transport to reconnect. The helper can also be called directly as `Live.reconnect(clock)`.

## RemoteLiveStream

```ts
import type { RemoteLiveStream } from "svelte-effect-runtime";

const clock: RemoteLiveStream<string> = get_clock("main");
```

`RemoteLiveStream<A, E>` is the client shape returned by `Query.live`. It is an Effect Stream whose errors are remote failures, with hidden transport metadata used by `Live`.

## Default runtime

If no runtime is registered, the package creates a default empty-layer runtime lazily. That is enough for pure effects and examples.
